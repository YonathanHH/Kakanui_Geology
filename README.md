# GEOL351 Digital Field Case Study

A professional single-project web showcase presenting GEOL351 field geology work as a structured digital case study.

## Overview

This project transforms GEOL351 field-based academic work into a clear and accessible web presentation. It is designed to communicate geological observations, interpretation, and scientific storytelling in a format that is more engaging than a traditional report.

## Scope

The website focuses specifically on the GEOL351 project and highlights:

- Regional geological context
- Field observations and key evidence
- Sedimentological and volcanological interpretation
- Methods and geological reasoning
- Major insights from the field study

## Purpose

The aim of this repository is to present one geology project as a polished standalone case study. It serves as a professional showcase of field interpretation, scientific communication, and geological analysis.
